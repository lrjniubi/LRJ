# LRJ
地平线 RDK X5 YOLO 图生文智能竞赛小车技术报告
一、环境部署
项目提供install_yolo_llm_deps.sh一键依赖安装脚本，自动适配 RDK X5 硬件环境，部署内容包含 ROS2 通信框架、地平线 BPU 推理工具链、YOLOv5 推理库、NMS 图像后处理工具、本地 VLM 大模型、IMU 姿态解算依赖、串口底盘驱动；脚本自动配置相机、I2C、串口硬件权限，部署完成后可直接启动节点。
二、关键可配置参数
1.	YOLO 视觉参数：障碍物检测置信度 0.3，人形立牌检测置信度 0.4，NMS 交并比 0.5，图像采样帧率 10fps；
2.	导航运动参数：最大线速度 0.8m/s，绕行最低限速 0.19m/s，预瞄距离区间 0.15~1.0m，绕行冷却时间 3s，最小安全行驶距离 0.5m；
3.	定位解算参数：Mahony 滤波 Kp=0.5，轮径误差校准系数 X=1.03、Y=1.125；
4.	场地安全参数：电子围栏 X 范围 0.1~4.3m，Y 范围 - 0.15~4.3m，越界触发回退控制逻辑。
三、硬件配套需求
计算核心：地平线 RDK X5 开发板，内置 BPU 硬件加速单元；行走底盘：OriginCar 阿克曼转向底盘，支持差速转向； 感知传感器：Aurora930 深度 RGB 相机、BMI088 六轴 IMU、500 线增量式轮编码器；底层控制单元：STM32 单片机，921600 波特率串口与上位机通信。
四、项目工程结构
采用标准 ROS2 工作空间ros2_ws，2026 年 6 月对外发布，遵循 Apache 2.0 开源协议；src 目录划分 5 个解耦功能包，配套模型文件、参数 yaml、调试可视化工具：
1.	qr_code_detection：二维码任务解析功能包
2.	imu_odom_fusion：多传感器定位融合功能包
3.	yolo_obstacle_yolo5：YOLOv5s 锥桶避障检测包
4.	yolo_vlm_caption：YOLOv5 人形检测 + VLM 图生文包
5.	race_master_control：分阶段赛事导航总控包
五、启动方式
1.	整套竞赛系统一键启动命令：ros2 launch race_master_control full_competition.launch.py
2.	模块化独立调试：每个功能包内置独立 launch 文件，可单独启动视觉检测、定位融合、导航控制节点，配合 RViz2 可视化 TF 坐标、检测框、融合里程数据。
六、标准化竞赛四阶段流程
1.	起点出发巡航阶段：车辆从发车点位驶出，沿预设航点行驶，全程开启锥桶障碍物检测与动态避障；
2.	二维码任务解析阶段：自主行驶至二维码点位，双模型识别读取赛道绕行指令，超时未识别自动切换顺时针路线；
3.	通道巡行与人形图生文阶段：根据二维码指令顺 / 逆时针沿赛道通行，直道区域启动 YOLOv5 人形检测，筛选最优清晰图像调用本地 VLM 生成立牌文字描述；
4.	视觉定点停车阶段：返回发车起点区域，识别 P 型停车标识，单应矩阵像素测距 + 多帧面积峰值判定，分段减速完成高精度停车。
七、五大核心功能模块
1.	二维码识别模块 双层级识别机制，高性能微信超分 CNN 模型为主，模型缺失自动降级 OpenCV 原生 QR 解码器；兼容深度相机、USB 摄像头两路图像输入，解码任务编号后发布/qr_code_result字符串话题，主控节点监听后切换赛道航点序列。
2.	YOLOv5s 避障感知模块 基于 RDK X5 BPU 硬件加速完成 YOLOv5s 推理，同步识别锥桶障碍物、停车标识；四层前置过滤 + 3 帧滑动窗口防抖消除单帧噪点误检，依据航向误差动态划分通行路径，搭配电子围栏约束生成自适应绕行轨迹，避障期间限制车速、禁止倒车。
3.	IMU 与底盘里程计多传感器融合模块 分为 IMU 采集、底盘里程积分、EKF 滤波三大协同节点；BMI088 IMU 以 1000Hz 采集原始惯性数据，Mahony 互补滤波解算稳定航向，EKF 扩展卡尔曼滤波融合轮式里程与 IMU 航向，输出无漂移/odom_combined融合里程，消除车轮打滑带来的长距离定位偏差。
4.	YOLOv5 图生文模块 C++ 节点完成 BPU 端 YOLOv5 实时检测，通过 0.4 置信度、0.5 NMS 筛选人形立牌目标；Python 业务节点定时采样图像，采用拉普拉斯方差评判清晰度、以目标面积为优先级筛选最优帧；调用本地 VLM 模型生成立牌文字描述，通过 ROS 话题输出至导航主控。
5.	多阶段惯性导航主控模块 50Hz 高速控制循环，搭载优化 Pure Pursuit 纯跟踪算法，实现动态预瞄距离、弯道自动限速、远近端姿态混合平滑过渡；有限状态机管控四阶段赛事，功能优先级从高至低：电子围栏＞扫码姿态调整＞YOLO 避障＞视觉停车＞基础航点导航。
